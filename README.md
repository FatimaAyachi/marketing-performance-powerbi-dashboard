# Marketing Performance Analysis Dashboard 

Ce projet présente la conception et le développement d'un tableau de bord décisionnel (Business Intelligence) sous **Power BI**, conçu pour analyser l'efficacité des campagnes marketing et optimiser l'allocation des budgets publicitaires.

## Fonctionnalités & Indicateurs Clés
- **Suivi du ROI :** Visualisation globale et détaillée du retour sur investissement par campagne.
- **Segmentation des Canaux :** Analyse comparative des performances selon les canaux d'acquisition (réseaux sociaux, search, e-mailing).
- **Graphiques Interactifs :** Utilisation de graphiques de dispersion (scatter plots) et de cartes de performance pour identifier les tendances et les anomalies rapidement.
- **Filtres Dynamiques :** Exploration des données par période, région ou type de public cible.

## Outils & Technologies
- **Business Intelligence :** Microsoft Power BI
- **Traitement des Données :** Modélisation relationnelle, DAX (Data Analysis Expressions)
- **Source de Données :** Fichiers de données structurés (CSV / Excel)
